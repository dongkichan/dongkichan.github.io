— The problem

A US client had a sprawl of business-critical PowerApps — fast to build, slow to scale, awkward to integrate, and expensive to evolve. Each one was load-bearing. Rewriting them by hand in React would take a year. Doing nothing meant accumulating maintenance debt at the rate of new features.

— Approach
  1. 01

    Stand up a React + Vite + Tailwind base with Zustand for state and React Query for server cache — a small, well-understood foundation that AI can reason about safely.

  2. 02

    Use Claude Code and Codex as the primary engineering surface: planning, scaffolding, refactoring, code review. I treat them like senior collaborators, not autocomplete.

  3. 03

    Deploy to Azure Static Web Apps via Azure DevOps (Repos + Pipelines). Keep handovers clean — every feature lands with documentation and a runbook.

  4. 04

    Integrate with Microsoft Graph, SharePoint, and external platforms; build Azure Automation runbooks where workflows belong server-side, not in the UI.
