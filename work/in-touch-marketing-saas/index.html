— The problem

Indicia's marketing-optimisation platform needed a grid that behaved like a spreadsheet — merge cells, unmerge cells, nest accordion tables inside cells, and round-trip to .xlsx export — but inside an Angular SPA where the underlying data model is relational, not 2D.

— Approach
  1. 01

    Built a custom grid engine that owns layout independent of data, so a 'merged region' is a first-class concept rather than a CSS hack.

  2. 02

    Translated Figma designs into responsive Angular components with strict TypeScript and reusable primitives — every column, every cell variant, documented and tested.

  3. 03

    Implemented spreadsheet-format export by separating display state from logical state, so the export is always the source-of-truth, never a screenshot.

  4. 04

    Integrated with a Java backend for persistence and complex business rules.

— What I took away

“When a UI fights its data model, the UI loses. Building a small dedicated layout engine for the grid was the unlock — once display and data were decoupled, every feature got cheaper.”
