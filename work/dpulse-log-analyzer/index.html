— The problem

Support engineers were grepping their way through 500,000+ row log files to find patterns in operational data. Manual, slow, error-prone, and unrepeatable — every investigation started from scratch.

— Approach
  1. 01

    Built a desktop tool (Electron + Angular) so engineers could keep working on the same machine where the logs lived — no upload step, no privacy concerns.

  2. 02

    Streaming parser instead of loading the whole file into memory — the UI stays responsive even on the worst log dumps.

  3. 03

    Pattern detection on top of structured filters; saved investigations so the next person doesn't start over.

  4. 04

    Shipped alongside Calendar Note (team collab w/ mentions, tasks) and a TF/Keras image classifier — the same year, three different stacks.
