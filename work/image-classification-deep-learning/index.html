— The problem

A specific class of operational images needed to be sorted and routed automatically. Hand-labelling didn't scale; rule-based heuristics kept missing edge cases. We needed a model — and an inference path that other apps could call without caring about Python.

— Approach
  1. 01

    Trained a CNN with transfer learning on top of a pretrained backbone in Keras — far less data needed, far better baseline than training from scratch.

  2. 02

    Tuned data augmentation, class weighting, and learning-rate schedules until validation accuracy was production-credible.

  3. 03

    Wrapped the model behind a clean inference API so consumers could send an image and get a class + confidence — no ML knowledge required on their side.

  4. 04

    Documented the training pipeline so retraining was a script, not a tribal-knowledge ritual.
